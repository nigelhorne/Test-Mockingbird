   75: =head1 DESCRIPTION
   76: 
   77: C<Test::Mockingbird::TimeTravel> provides a lightweight, deterministic
   78: time-control layer for Perl tests. It does B<not> monkey-patch
   79: C<CORE::time()>. Instead it provides a dedicated C<now()> function and a
   80: small set of declarative operations that manipulate an internal frozen clock.
   81: 
   82: =head1 LIMITATIONS
   83: 
   84: =over 4
   85: 
   86: =item C<now()> is not a drop-in for C<time()>
   87: 
   88: Production code must call C<now()> for time control to take effect. Code
   89: that calls C<CORE::time()>, C<POSIX::time()>, or C<Time::HiRes::time()>
   90: directly is not affected.
   91: 
   92: =item Fractional seconds not supported
   93: 
   94: All timestamps are integer epoch seconds. Sub-second resolution is not
   95: available.
   96: 
   97: =item Thread safety
   98: 
   99: C<$ACTIVE>, C<$CURRENT_EPOCH>, and C<$BASE_EPOCH> are package globals.
  100: Concurrent threads that manipulate time state will race.
  101: 
  102: =back
  103:
