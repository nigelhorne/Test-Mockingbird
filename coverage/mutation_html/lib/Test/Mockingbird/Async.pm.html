   71: =head1 DESCRIPTION
   72: 
   73: C<Test::Mockingbird::Async> extends L<Test::Mockingbird> with helpers for
   74: testing code that uses L<Future>-based asynchronous APIs.
   75: 
   76: All mocks and spies installed by this module use the same underlying stack
   77: as the core engine. C<restore_all()>, C<unmock()>, and C<diagnose_mocks()>
   78: work identically to their core counterparts. Every installed layer is
   79: recorded in C<diagnose_mocks()> with a type of C<mock_future_return>,
   80: C<mock_future_fail>, C<mock_future_sequence>, C<mock_future_once>, or
   81: C<async_spy>.
   82: 
   83: C<async_spy> also writes to the call-order log, so
   84: C<assert_call_order()> works across a mix of plain spies and async spies.
   85: 
   86: =head2 Dependency
   87: 
   88: This module requires the L<Future> distribution (available from CPAN).
   89: It is not a mandatory dependency of L<Test::Mockingbird> itself; the
   90: module loads C<Future> on first use and croaks with a helpful message if
   91: it is not installed.

  291: =head2 async_spy
  292: 
  293: Wrap a method so that every call is recorded along with the C<Future> it
  294: returned. The original method is still called and its return value is
  295: passed back to the caller unchanged.
  296: 
  297:     my $spy = async_spy 'My::DB::fetch';
  298:     My::DB->fetch(id => 1);
  299: 
  300:     my @calls = $spy->();
  301: 
  302:     my $call = $calls[0];
  303:     # $call->{args}   is [ 'My::DB::fetch', $invocant, id => 1 ]
  304:     # $call->{future} is whatever Future the original returned
  305: 
  306:     my $result = $call->{future}->get;   # inspect resolved value
  307: 
  308: Unlike the plain C<spy()> coderef (which returns arrayrefs), C<async_spy>
  309: returns hashrefs so the C<future> field is unambiguous.
  310: 
  311: C<async_spy> writes to the call-order log, so C<assert_call_order()> works
  312: across a mix of plain and async spies.
  313: 
  314: =head3 Limitations
  315: 
  316: C<async_spy> assumes the spied method returns a C<Future>. If the method
  317: returns a plain value the C<future> field in each call record will hold that
  318: value rather than a C<Future>, and calling C<< ->get >> on it will fail.
  319: 
  320: =head3 API SPECIFICATION
  321: 
  322: =head4 Input

  324:     target -- Str, 'Pkg::method' or ('Pkg', 'method')

  326: =head4 Output
  327: 
  328:     returns: CodeRef; yields the list of call records, each
  329:              { args => [ 'Pkg::method', @args ], future => $returned }
